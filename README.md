# Lashroom — website `lashroom.cz`

Landing/promo website for `lashroom.cz` (professional eyelash extensions and courses in Olomouc).

## Technologies

- **Astro 4**
- **Tailwind CSS v4 (alpha)** via `@tailwindcss/vite` and `src/styles/global.css` file
- **Alpine.js** (connected via CDN in `src/components/BaseHead.astro`)
- **GSAP** (animations)
- **SEO** via `astro-seo` (`SEO` component in `src/components/BaseHead.astro`)
- **Sitemap** via `@astrojs/sitemap` (see `astro.config.mjs`)

## Requirements

- **Node.js LTS**
- **npm**

## Commands

All commands are run from the repository root:

| Command                   | Action                                             |
| :------------------------ | :------------------------------------------------- |
| `npm install`             | Install dependencies                               |
| `npm run dev`             | Start dev server (default `http://localhost:4321`) |
| `npm run build`           | Build production version in `./dist/`              |
| `npm run preview`         | Preview the production build locally               |
| `npm run astro -- --help` | Astro CLI help                                     |

## Project Structure

Key directories:

```text
/
├── public/                 # Static files (images, icons, etc.)
├── src/
│   ├── components/          # UI components (Astro)
│   │   ├── global/          # Navigation, footer, contacts, course, etc.
│   │   └── landing/         # Landing sections (Hero, About, Price, Faq, ...)
│   ├── layouts/             # Page layouts
│   ├── pages/               # Routes (e.g., `index.astro`)
│   └── styles/              # Global styles
└── package.json
```

Import aliases are configured in `tsconfig.json`:

```ts
@/* -> src/*
```

## Tailwind CSS v4

Tailwind is connected directly in `src/styles/global.css`:

```css
@import "tailwindcss";
@plugin "@tailwindcss/typography";
@plugin "@tailwindcss/forms";
@plugin "tailwind-scrollbar-hide";
```

## Dark Mode

- Theme is controlled via the `dark` class on `<html>`.
- Selected theme is stored in `localStorage` with the key `theme` (`light`/`dark`).
- Initialization and toggle are located in `src/components/BaseHead.astro`.

## SEO and Sitemap

- SEO tags are generated via `astro-seo` in `src/components/BaseHead.astro`.
- Sitemap is generated by `@astrojs/sitemap` integration.

Important: for a correct sitemap, you need to set the real domain in `astro.config.mjs` (`site` field).
